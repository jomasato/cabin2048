# Cabin 2048

1台の端末をまわして遊ぶ2048。機内で使うために作ってある。

**遊ぶ → https://jomasato.github.io/cabin2048/**

## 何が普通の2048と違うか

**同じ運で競う。** ラウンドを始めた時点でタイルの出る順番を2600手ぶん先に確定させ、そのラウンドの全員が同じ列を引く。盤面は打ち方で当然ちがうが、引いた運は全員そろう。「4ばっかり出た」は言い訳にならない。

盤面が変化しないスワイプは乱数を消費しないので、無駄打ちで列がズレることもない。取り消しは無し。

同点の場合は**手数が少ない方が上位**。

## ルールは3つある

ラウンドを始めるときに選ぶ。

**2048** — 同じ数字をくっつける。タイルは端まで滑る。

**1·2·3** — 1と2で3をつくり、そこからは同じ数同士で倍々（3+3=6、6+6=12…）。**1と1、2と2はくっつかない**ので盤面が詰まりやすい。札は1マスずつしか動かず、1回のスワイプで各列に起きる操作は1つだけ。新しい札はスワイプしてきた側の逆端から、**実際に動いた列のどれか**に入る。

1·2·3の肝は**次に来る札が見えること**。全員が同じ予告列を見るので、運ではなく計画の勝負になる。スコアは最終盤面だけが対象で、3以上の札が3の累乗で加算される（3→3点、6→9点、12→27点…）。**1と2は何枚あっても0点**。だから大きい札を1枚育てる方が、小さい札で盤面を整えるより強い。

**7×7** — 1〜7の数字が書かれた玉を好きな列に落とす（列をタップ）。玉は**自分と同じ行または列の埋まっているマス数が、自分の数字と一致した瞬間に消える**。消えると上が落ちてきて条件が変わり、**連鎖**する。灰色のブロックは行と列の数には数えられるが自分からは消えず、消えたマスに隣接すると**ひび割れ**、もう一度隣接すると**数字の玉になって開く**。一定手数ごとに下からブロックの行がせり上がり、天井まで押し上げられたら終わり。

スコアは1回の波で消えた枚数の2乗 × 何波目か。**盤面を広く消すことと、連鎖を深くすることの両方**が効くが、連鎖の方が伸びる。

せり上がりの間隔（`RISE_EVERY`）と初期ブロック行数（`START_ROWS`）は原典の数字ではなく、**1ラウンド3〜5分に収まるよう独自に調整している**。長すぎ／短すぎる場合はここをいじる。

スコアの桁がルールごとに全く違うので、順位表と自己ベストはルールごとに別々に記録される。

## 機内で使う準備

3までやって初めて安心していい。

1. Safariで上のURLを開き、共有ボタンから**「ホーム画面に追加」**
2. 追加したアイコンから**一度起動**する（ここで必要なものが端末に焼き付く）
3. 搭乗前に**機内モードをONにして、もう一度アイコンから起動**できるか確認

ブラウザのタブのままだと機内で開けないことがある。スコアとメンバーはこの端末の中にだけ残り、サイトデータを消すと一緒に消える。

## 構成

外部依存ゼロ。CDNもWebフォントも使っていない（機内で取りに行けないため）。書体はiOSの `ui-rounded` / `ui-monospace` をそのまま使う。

| | |
|---|---|
| `index.html` | 本体。これが唯一の編集対象 |
| `sw.js` | Service Worker。キャッシュ優先。**デプロイのたびに `CACHE_VERSION` を上げる** |
| `manifest.webmanifest` | ホーム画面に追加したときの見え方 |
| `tools/make_icons.py` | アイコン生成（Pillow） |
| `tools/make_artifact.py` | `index.html` からArtifact版を切り出す |

`index.html` 内の `shared:start` / `shared:end` マーカーの間が、Artifact版と共通の中身。外側はスタンドアロン用の包装なので、ゲームをいじるときはマーカーの内側だけを触る。

```sh
python tools/make_icons.py                 # アイコンを作り直す
python tools/make_artifact.py              # build/cabin2048.html にArtifact版を出す
```

### デプロイ

`main` に push すると GitHub Pages が自動で公開する。**その前に `sw.js` の `CACHE_VERSION` を上げること。** 上げないと、すでにホーム画面に追加した端末は古い版を掴んだまま更新されない。
