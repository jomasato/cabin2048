# Cabin 2048

1台の端末をまわして遊ぶ2048。機内で使うために作ってある。

**遊ぶ → https://jomasato.github.io/cabin2048/**

## 何が普通の2048と違うか

**同じ運で競う。** ラウンドを始めた時点で「n手目に、空いているマスの何番目に、いくつが出るか」を2600手ぶん先に確定させ、そのラウンドの全員が同じ列を引く。盤面は打ち方で当然ちがうが、引いた運は全員そろう。「4ばっかり出た」は言い訳にならない。

盤面が変化しないスワイプは乱数を消費しないので、無駄打ちで列がズレることもない。取り消しは無し。

同点の場合は**手数が少ない方が上位**。

## 機内で使う準備

3までやって初めて安心していい。

1. Safariで上のURLを開き、共有ボタンから**「ホーム画面に追加」**
2. 追加したアイコンから**一度起動**する（ここで必要なものが端末に焼き付く）
3. 搭乗前に**機内モードをONにして、もう一度アイコンから起動**できるか確認

ブラウザのタブのままだと機内で開けないことがある。スコアとメンバーはこの端末の中にだけ残り、サイトデータを消すと一緒に消える。

## 構成

外部依存ゼロ。CDNもWebフォントも使っていない（機内で取りに行けないため）。書体はiOSの `ui-rounded` / `ui-monospace` をそのまま使う。

| | |
|---|---|
| `index.html` | 本体。これが唯一の編集対象 |
| `sw.js` | Service Worker。キャッシュ優先。**デプロイのたびに `CACHE_VERSION` を上げる** |
| `manifest.webmanifest` | ホーム画面に追加したときの見え方 |
| `tools/make_icons.py` | アイコン生成（Pillow） |
| `tools/make_artifact.py` | `index.html` からArtifact版を切り出す |

`index.html` 内の `shared:start` / `shared:end` マーカーの間が、Artifact版と共通の中身。外側はスタンドアロン用の包装なので、ゲームをいじるときはマーカーの内側だけを触る。

```sh
python tools/make_icons.py                 # アイコンを作り直す
python tools/make_artifact.py              # build/cabin2048.html にArtifact版を出す
```

### デプロイ

`main` に push すると GitHub Pages が自動で公開する。**その前に `sw.js` の `CACHE_VERSION` を上げること。** 上げないと、すでにホーム画面に追加した端末は古い版を掴んだまま更新されない。
